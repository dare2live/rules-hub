Rules Hub 重写自检

这个页面只有一个用途：告诉你 Quantumult X 的重写链路是否正常。
页面顶部如果出现绿色横幅 → MITM 与脚本执行都正常，重写规则可以生效。
没有横幅 → 重写没跑起来，去广告自然也不会生效。
没有横幅时，按顺序检查：
  1. Quantumult X → 设置 → MITM → 证书是否已安装、并在「设置 → 通用 → 关于本机 → 证书信任设置」里打开完全信任
  2. 本配置的 [mitm] 里 hostname 是否包含本页域名
  3. 重写总开关是否打开；[rewrite_remote] 里的条目是否处于启用状态
  4. 把本配置删掉重新导入一次（QX 有时会缓存旧的重写文件）
