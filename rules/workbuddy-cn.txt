# WorkBuddy 国内服务（腾讯侧）：直连
# 两个客户端（WorkBuddy 国版 / WorkBuddy AI 海外版）共用同一套后端，
# 域名集合完全一致，所以这里按「域名归属」而不是「哪个 App」来拆。
# 国内域名绕新加坡会明显变慢（腾讯云北京 / 广州），必须直连。
#
# 注意：本列表必须排在 custom_direct（rules/direct.txt）之前才有意义，
# 否则下面的 tencent.com / myqcloud.com 子域会先被 direct.txt 的
# 「DOMAIN-SUFFIX,tencent.com」吃掉，WorkBuddyCN 组等于空组，切了没反应。

# 单列 account.tencentid.com 漏掉了 pre-account.tencentid.com（客户端登录会用到）。
DOMAIN-SUFFIX,tencentid.com

DOMAIN-SUFFIX,identity.tencent.com
